# Portfólio — Iarley Gabriel

Portfólio desenvolvido a partir do template iPortfolio com Bootstrap. O layout original foi preservado, com personalização de textos, formação, conhecimentos, projetos e cor de destaque.

## Como visualizar
Abra o arquivo `index.html` no navegador.

## Antes de publicar
- Troque o avatar pelas suas próprias fotos, se desejar.
- Confira os links dos projetos e adicione os repositórios individuais quando estiverem públicos.
- Atualize o link do LinkedIn quando tiver o endereço do perfil.
- Publique o projeto no GitHub e depois importe o repositório na Vercel.
